PDF 批量打印工具 —— 使用说明
================================================

【怎么用】
1. 双击 PdfBatchPrint.exe 打开程序（render_pdf.py 是配套脚本，不要删、不要移走）。
2. 添加要打印的文件（PDF 和图片都行，可以混着加）：
   - 「添加文件」：多选 PDF / 图片；
   - 「添加文件夹」：把这个文件夹（含子文件夹）里的 PDF 和图片全部加进来；
   - 也可以把文件 / 文件夹直接拖进窗口，或拖到 exe 图标上。
3. 选择打印机：网络打印机请选带 \\Server1\ 前缀的那台
   （本机那个不带前缀的同名打印机端口是 PORTPROMPT:，是占位，打不出来；
     程序会在它后面标注「[本机占位端口，打不出纸]」，并自动帮你改用 \\Server1\ 那台）。
4. 打印设置：
   份数      每个文件打几份
   双面      单面 / 双面长边 / 双面短边
   打印引擎  精确渲染（推荐）：PDF 按 dpi 渲染成图再打印，纸张和缩放最可控
             WPS 原样打印：交给 WPS 打印，保留矢量，可能出现 WPS 窗口和对话框
   纸张      自动（按原图）：A3 图自动用 A3、A4 自动用 A4；也可强制指定
   方向      自动（按图纸）：每页单独判断，宽>高用横向、高>宽用纵向，
              同一批里横竖混排也不会打歪；也可强制「横向」或「纵向」
   边距      默认 1mm：在可打印区里再留出的安全边距（毫米）。
               真实打印机的可打印区比纸面小（四周约 4.2mm），A3 图缩到 A4 时
               底部最容易贴边被裁，遇到「最下面看不到」就改成 3mm 或 5mm 再打
   缩放      适合纸张 = 整张图缩放到纸张可打印区域，保证不被裁
              实际大小 = 1:1，超出纸张的部分会被裁掉
   分辨率    300dpi 足够出图；调高更清晰但更慢、文件更大
   灰度      开 = 按灰度输出，省墨
   合并      不合并（原样打印）
              合并：每页 1 / 2 / 4 张 —— 把多个文件排到一张纸上再打印，
              打电子发票就用「每页 2 张（发票推荐）」：12 张发票 = 6 页 A4
              图片也能参与合并，图片和发票可以混着拼
   裁掉白边  默认开：合并前先自动识别每张发票的实际内容范围（文字+线条+图片），
              把四周空白裁掉再排版，一页能放得更满、字也更大
   合并另存… 只把合并后的 PDF 存到你选的位置，不打印，用来先看效果
5. 列表里只打印【打勾】的行，不想打的取消勾选即可。
6. 点「打印预览」逐页看实际排版（白纸 = 纸张，蓝虚线 = 打印机可打印区，
   红色 = 会超出可打印区、打印时会被裁掉的部分）；可翻页、放大、适应窗口。
7. 点「开始打印」。进度条和日志区会逐条显示结果，失败的会写原因。

【图片打印（1.4 版新增）】
支持的格式：png、jpg/jpeg、bmp、gif、tif/tiff、webp（webp 需要 Pillow，便携包已带）。
   - 一张图算 1 页，图片和 PDF 混在同一个列表里一起打，纸张/方向/边距/缩放/合并/预览都照常生效。
   - 图片的「页面尺寸」按图片文件里记录的 dpi 换算：1200×800 的图，标 96dpi 就是 317×212mm，
     标 300dpi 就是 102×68mm。没有 dpi 信息的按 96dpi 算。
   - 照片常见坑：手机/相机照片常标 72~96dpi，换算出来会超过 A3，于是「纸张：自动」会选 A3。
     想打 A4 就把「纸张」直接选 A4，「缩放」保持「适合纸张」，图会等比铺满 A4、不会被裁。
   - 用「WPS 原样打印」打图片时，程序会先把图片转成临时 PDF 再交给 WPS，打完自动删除临时文件。

【常见问题】
- 点了打印但打印机没动静：多半是打印队列里卡了旧任务。
  卡在本机队列 → 管理员运行 PowerShell：Restart-Service Spooler -Force，再重新点「开始打印」。
  卡在 Server1（\\Server1\ 那台显示“正在打印 / Printing, Retained”）→ 本机取消不了，
  要到 Server1 上用管理员账号删掉卡住的任务，或在 Server1 上重启 Print Spooler 服务。
- 图纸边框被裁：把「缩放」设为「适合纸张」，纸张设为「自动（按原图）」，方向设为「自动（按图纸）」。
- A3 图缩到 A4 打、最下面被裁：1.1 版已修正排版偏移（旧版整体偏右下 4.2mm，底部丢 3mm）；
  仍嫌贴边就把「边距」调成 3mm / 5mm。想先看效果可以用「Microsoft Print to PDF」
  打一份 PDF 对照，不浪费纸。
- 横竖混排：默认「方向：自动（按图纸）」就对，日志会打印每张图的判断结果
  （例如「页面 420x297mm → 横向 / A3」）；要全部统一方向就手动选「横向」或「纵向」。
- A2 图（如 CQ00010.pdf）：本机打印机最大 A3，会自动等比缩到 A3（约 71%）；
  要 1:1 只能用 A2 幅面设备或分块打印。
- 发票合并打印：把发票 PDF 都加进列表 → 「合并」选「每页 2 张（发票推荐）」
  → 勾上「裁掉白边」→ 纸张选 A4 → 开始打印。想先看效果就点「合并另存…」。
  合并是矢量的（不栅格化），放大也清晰；一张 A4 放 4 张就选「每页 4 张」，字会偏小。
- 图片打出来尺寸不对（照片变成 A3）：见上面【图片打印】里「照片常见坑」那条，纸张手动选 A4 即可。
- 提示「无法识别图片格式」：极少数格式 MuPDF 不认，程序会改用 Pillow 转换；若仍失败，
  说明这台机器没有 Pillow，把图片另存成 png/jpg 再打，或 pip install pillow。
- 多页 PDF（例如合并后的发票）页数翻倍：1.1 版以前的 bug（N 页会打成 N×N 页），
  1.2 版已修，现在页数和源文件一致。
- 打印预览（1.3 版新增）：点「开始打印」旁边的「打印预览」，会按当前纸张/方向/边距/缩放/合并设置
  逐页画出效果。看到红块说明那一块超出可打印区会被裁掉 → 调大「边距」或换大纸张；
  合并开启时预览的是合并后的结果（12 张发票 = 6 页）。快捷键：Esc 关闭，PageUp/PageDown 翻页，
  Ctrl+滚轮缩放。预览不产生打印任务、不浪费纸。
- 设置会自动记住（%APPDATA%\PdfBatchPrint\settings.ini），下次打开沿用。
- 窗口里双击某个文件，会用系统默认程序打开它，方便先确认图纸。

【命令行 / 批处理】
  PdfBatchPrint.exe --cli --folder "D:\图纸" --printer "\\Server1\HP MFP M433 PCL 6"
  PdfBatchPrint.exe --cli --files "a.jpg;b.png;c.webp" --printer "..." --paper A4   （打图片）
  PdfBatchPrint.exe --cli --files "a.pdf;b.pdf" --printer "..." --paper A3 --dpi 300
  PdfBatchPrint.exe --cli --files "a.pdf" --printer "Microsoft Print to PDF" --print-to-file "D:\预览.pdf"
  PdfBatchPrint.exe --cli --folder "D:\图纸" --printer "..." --orient portrait   （强制纵向；默认 auto 按每张图纸自动横竖）
  PdfBatchPrint.exe --cli --folder "D:\图纸" --printer "..." --paper A4 --margin 3   （A3 缩 A4 底部被裁时，加大安全边距）
  PdfBatchPrint.exe --cli --files "a.pdf;b.pdf;c.pdf" --printer "..." --merge 2up --crop-invoice 1 --paper A4   （发票合并：每页 2 张、裁白边）
  PdfBatchPrint.exe --cli --files "a.pdf;b.pdf" --merge 2up --crop-invoice 1 --save-merged "D:\合并发票.pdf" --printer "Microsoft Print to PDF" --print-to-file "D:\临时.pdf"   （只生成合并 PDF，先看效果）
  全部参数：PdfBatchPrint.exe --help
  退出码：0 全部成功 / 1 有失败 / 2 参数错误 / 3 缺少 Python 环境

【注意】
「精确渲染」引擎需要本机有 Python + PyMuPDF。程序会自动查找本机已有环境
（%USERPROFILE%\.dsh 运行时、C:\Python312、PATH 里的 python 等），通常无需配置。
查不到时仍可用「WPS 原样打印」引擎。

更详细的说明见 pdfbatch 目录里的 README.md。

【拷到别的电脑上用（便携版，1.4 版）】
- 便携包见桌面的 PDF批量打印工具_便携版_v1.4.zip，解压后是完整目录（含打印预览、发票合并、图片打印）。
- 整个文件夹一起拷，不要只拷 exe：PdfBatchPrint.exe、render_pdf.py、python\ 三个都在才行。
- 目标电脑：Windows 7 SP1 及以上；需要系统自带 .NET Framework 4.x（Win10/11 默认已有，Win7 可能要装）。
- 在目标电脑上先装好打印机驱动并添加打印机（共享打印机用 \\服务器名\打印机名，例如 \\Server1\HP MFP M433 PCL 6），
  程序会把本机那个占位端口的同名打印机标成「[本机占位端口，打不出纸]」，并自动改用共享的那台。
- python\ 是随包的精简 Python 3.12 + PyMuPDF，只服务本程序，不需要安装、不写注册表、不影响电脑上已有的 Python。
  日志里出现「渲染引擎就绪: ...\python\python.exe」就说明用的是内置环境。
- 建议先拷到本地硬盘（例如 D:\PDF批量打印工具）再运行；直接从 U 盘/网络盘运行会慢一些。
- 设置存在 %APPDATA%\PdfBatchPrint\settings.ini，换电脑后是新的默认值，重新选一次打印机即可。

【1.4.1 修复（2026-11-03）】
- 「合并 + 裁掉白边」时，发票最右边的细边框线和彩色边条会被裁掉（预览里右边少一条边就是它）。
  原因是自动裁白边只按文字/图形位置算内容框，宽度为 0 的竖线被当成空矩形忽略了。
  现在改为手工合并内容框并向外多留 1pt，边框和彩色边条都能完整保留。
  如果仍怀疑有内容被裁，把「裁掉白边」取消再对比一次即可确认。
