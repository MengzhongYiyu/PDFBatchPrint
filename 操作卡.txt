PDF批量打印工具 —— 操作卡（全是中文，照着点就行）

═══════════════════════════════════════
第一次用，先准备两样东西
═══════════════════════════════════════

1. GitHub 用户名
2. 一个「访问令牌」——一串以 ghp_ 开头的长密码
   怎么拿：
   浏览器打开 github.com
   → 右上角头像 → Settings（设置）
   → 左边最下面 Developer settings（开发者设置）
   → Personal access tokens → Tokens (classic)
   → 右上角 Generate new token (classic)
   → Note 里随便写：pdfbatch
   → Expiration 选 90 days（90 天）
   → 勾选 repo 这一整块
   → 最下面点 Generate token
   → 复制页面上出现的那串字符（只显示一次，务必先存记事本）

═══════════════════════════════════════
每天用的三个双击
═══════════════════════════════════════

1. build.cmd            改完代码 → 编译（黑色窗口自己会关）
2. selftest.cmd         自检 → 6 项都显示 PASS 就没问题
3. 发布到GitHub.cmd     把代码传到 GitHub
                        会依次问你：GitHub 用户名、粘贴令牌

═══════════════════════════════════════
要把便携版发给别人
═══════════════════════════════════════

双击 发布便携包到Release.cmd
→ 只要粘贴令牌 → 等 1~5 分钟 → 完成
（上传的是 dist\PDF批量打印工具_便携版_v1.4.1.zip，约 41MB）

═══════════════════════════════════════
小提示
═══════════════════════════════════════

· 令牌等于密码，别发给别人；90 天后过期就重新生成一个
· 每次推送都要重新输一次令牌，这是正常的
· 推送失败最常见的三个原因：
  1) GitHub 网页上还没建仓库 PDFBatchPrint
  2) 令牌没勾 repo，或者复制少了字符
  3) 密码栏粘成了登录密码 —— 必须是令牌
